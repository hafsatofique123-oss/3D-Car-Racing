===============================================================
       3D SPEED RACER — NITRO REALISTIC EDITION
===============================================================

HOW TO PLAY (2 EASY WAYS):

OPTION 1 (EASIEST):
- Simply double-click "index.html" in File Explorer to open it in
  Google Chrome, Microsoft Edge, or any modern browser.
  (All libraries, textures, and scripts are bundled locally — zero
  CORS issues and no internet connection required!)

OPTION 2 (DEVELOPER / LIVE SERVER):
- Open this folder in VS Code.
- Right-click "index.html" and choose "Open with Live Server"
  (or run `npx serve .` in terminal).

---------------------------------------------------------------
KEYBOARD CONTROLS:
- Steer: Left / Right Arrows or A / D
- Accelerate (Gas): Up Arrow or W
- Brake / Reverse: Down Arrow or S
- Nitros Boost: SPACEBAR, SHIFT, or N key (or tap the NITRO button)
- Toggle Sound: Click the 🔊 / 🔇 button in the top right

TOUCH / MOBILE CONTROLS:
- On-screen touch buttons for Steer Left/Right, Gas, Brake,
  and a prominent [ 🔥 NITRO ] button.

---------------------------------------------------------------
